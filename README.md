# دليل اختيار السكوتر في مصر

موقع عربي ثابت يقارن فيدل 3 وJet 14 DD كاربراتير وJet 14 EVO وJet X المحلي، ويضم مصادر البحث وكتالوج قطع الغيار والحاسبات ومكتبة تنزيلات.

## التشغيل

لا توجد تبعيات أو خطوة بناء مطلوبة. شغّل خادم ملفات ثابتًا من جذر الريبو، مثل `npx serve .`، ثم افتح العنوان الذي يظهر في الطرفية. الموقع لا يحتاج قاعدة بيانات أو مفاتيح وصول.

## الملفات

- `index.html`: صفحة الموقع والأقسام.
- `style.css`: أنماط العرض المتجاوب.
- `site.js`: بيانات الموقع المدمجة والحاسبات والفلاتر والتصدير.
- `catalog.json`: بيانات كتالوج قطع الغيار.
- ملفات `*.md` و`*.csv` و`*.txt`: الأبحاث والجداول وطلب التسعير.
- `assets/`: الصور والخط المستخدم.
- `scooter-guide-complete.zip`: نسخة قابلة للتنزيل من الموقع والكود، بدون `.git` أو `.vercel` أو إعدادات الحسابات.

## التحديث والنشر

حرّر ملفات HTML وCSS وJavaScript مباشرة. البيانات مدمجة في بداية `site.js` لتعمل الفلاتر والتنزيلات في المعاينات المعزولة أيضًا؛ عند تعديل البيانات حدّث معها JSON وCSV والتقارير المرتبطة، ولا تفترض أن تعديل ملف واحد يحدث باقي الصيغ تلقائيًا. حدّث أرشيف ZIP بعد أي تعديل حتى لا يقدم نسخة أقدم من الموقع.

على Vercel اختر إطار العمل `Other`، بدون أمر تثبيت أو بناء، واجعل مجلد الإخراج `.`. المستودع برايفت، لكن نشر الموقع يتيح الملفات الموجودة فيه عبر الرابط؛ لا تضف أي أسرار أو معلومات شخصية.

## حدود البيانات والحقوق

البحث لقطة مؤرخة في 15 نوفمبر 2026 وليس تغذية أسعار حية. السعر والتوفر والتوافق تخضع لتحفظات وروابط الأدلة داخل الموقع والتقارير. لا تُعد الحاسبات تعليمات صيانة أو إثباتًا لاستهلاك الوقود. الصور والخط والمحتوى الخارجي تظل خاضعة لحقوق أصحابها، ولا يمنح تنزيل المستودع ترخيصًا لحقوق الغير.
